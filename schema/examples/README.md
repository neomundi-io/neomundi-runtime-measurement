## A known historical inconsistency, preserved as-is

`rgc-v0.1-within-bounds-no-review-real-signed.json` has `measurement_status: "complete"` together with `measurement_coverage: 0.6`. Under the v0.2 schema this combination is invalid (`complete` requires `coverage = 1.0`). The source repository documents this itself as the "historical limitation" that motivated v0.2, and explicitly states the signed v0.1 artifact must remain unchanged — modifying it would invalidate its hash and signature. This repository preserves that inconsistency rather than silently correcting it.

## Verification performed

While assembling this repository, both real v0.1 examples were independently re-verified end-to-end (SHA-256 recomputation over the canonical `{identity, provenance, observation, governance}` payload, plus full Ed25519/JWS signature verification against `rgc-v0.1-public-jwks-test-key.json`), and all four RGC examples were validated against their declared schema version — all passed with zero errors. This does not make the *content* of any example more authoritative than stated above; it confirms the *transcription into this repository* is byte-for-byte faithful to the source.

None of these examples should be used as a target for schema validation in a production integration without also consulting [docs/INTEROPERABILITY.md](../../docs/INTEROPERABILITY.md) and the current live schema at `GET /v1/rgc/schema`.
