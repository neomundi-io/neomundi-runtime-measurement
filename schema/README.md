# Schema

**Authoritative schema not yet frozen / not supplied.**

No complete, definitive JSON Schema for a NeoMundi measurement or interoperable contract was present in the source material used to build this repository. The API Integration Guide references `schema/contract-v0.1.schema.json` and `schema/contract-v0.2.schema.json` as existing in a separate reference interoperability repository, but those schema files themselves were not supplied here.

This directory therefore contains **examples only**, not a schema definition. See [examples/README.md](./examples/README.md) for what each example is and its exact status.

Do not treat any example in this directory as a complete or binding field list. Per the [Measurement Contract](../docs/MEASUREMENT_CONTRACT.md), field names, exact JSON locations, and enums are explicitly not yet frozen.
